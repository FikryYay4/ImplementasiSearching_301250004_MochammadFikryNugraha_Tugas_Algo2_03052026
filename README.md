## 📌 Deskripsi

Project ini merupakan implementasi dua algoritma pencarian dasar dalam ilmu komputer:

- 🔍 **Linear Search (Sequential Search)**
- ⚡ **Binary Search**

Program dibuat menggunakan **Python** dengan konsep **modular programming**, sehingga kode lebih terstruktur, rapi, dan mudah dikembangkan.

---

## 🧠 Konsep Algoritma

### 🔍 Linear Search
- Mengecek data satu per satu
- Tidak membutuhkan data terurut
- Cocok untuk data kecil

---

### ⚡ Binary Search
- Membagi data menjadi dua bagian
- Mengurangi ruang pencarian setiap iterasi
- Wajib menggunakan data yang sudah terurut

## 🔄 IPO (Input - Process - Output)

### 🟢 Input
- Jumlah data
- Nilai data (input menggunakan looping)
- Nilai target pencarian

### 🔵 Process
- Linear Search → pencarian satu per satu
- Binary Search → pencarian dengan pembagian data

### 🔴 Output
- Status data ditemukan / tidak ditemukan
- Posisi indeks data
